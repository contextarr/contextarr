# Handoff Notes

## Summary

The fictional handoff format captures what changed, what was verified, what remains out of scope, and the next recommended phase.

## Fields

| Field | Purpose |
|---|---|
| Changed | Summarizes behavior or files |
| Verified | Lists checks run |
| Out of scope | Prevents accidental expansion |
| Next | Names the next coherent task |

## Notes

This pattern is reusable across coding-agent handoffs without exposing private project data.
