# Development Workflow

## Summary

The fictional workflow moves from repo inspection to scoped implementation, then through tests, review, and a clean commit.

## Stages

1. Confirm current state.
2. Make the smallest coherent change.
3. Add or update focused tests.
4. Run verification.
5. Commit with a concise message.
