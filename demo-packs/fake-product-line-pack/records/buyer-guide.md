# Buyer Guide

## Summary

The fictional buyer guide helps assistants explain which Atlas reference model fits a generic team scenario without using real pricing or availability claims.

## Fit Signals

| Signal | Suggested Model |
|---|---|
| Simple setup and narrow scope | Atlas Mini |
| Balanced features and repeatable workflows | Atlas Core |
| Higher capacity and complex coordination | Atlas Max |
| Unknown requirements | Start with discovery questions |

## Notes

All model names, fit signals, and positioning are invented for public Contextarr demos.
