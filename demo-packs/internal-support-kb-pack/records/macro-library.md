# Macro Library

## Summary

The fictional macro library provides reusable response patterns for common support moments while requiring agents to verify the relevant article before replying.

## Macro Patterns

| Pattern | Safe Use |
|---|---|
| Clarify symptom | Ask for customer-visible details only |
| Confirm workaround | Summarize a documented temporary path |
| Set expectation | Explain review timing without private queue names |
| Close loop | Restate the next step and invite a follow-up symptom |

## Notes

Macros are examples of tone and structure, not real approved customer messages.
