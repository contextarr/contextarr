# Quality Review Rubric

## Summary

The fictional support team reviews KB content for correctness, safe disclosure, customer clarity, and current ownership before approving it for assistant exports.

## Rubric

| Criterion | Passing Standard |
|---|---|
| Accuracy | Matches an approved source note |
| Safety | Excludes private labels, logs, and account details |
| Clarity | Gives one clear customer-facing next step |
| Freshness | Includes a current review date and source status |

## Notes

This rubric demonstrates review metadata without representing any real support operation.
