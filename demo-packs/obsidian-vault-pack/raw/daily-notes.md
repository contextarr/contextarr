# Daily Notes Source Note

Vault policy note for fictional daily notes.

Daily notes are treated as draft-heavy source material. They may contain personal fragments, unfinished decisions, or transient observations, so they do not become trusted export records unless reviewed and summarized.

| Note state | Pack handling |
| --- | --- |
| raw daily note | excluded from default export |
| reviewed excerpt | can become a sourced record |
| private fragment | redacted or left out |

The demo note contains no real journal content or personal schedule details.
