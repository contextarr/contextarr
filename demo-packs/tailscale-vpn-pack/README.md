# Tailscale VPN Pack

Public-safe starter context for a fictional Tailscale tailnet.

This starter pack is a curated local example, not a marketplace listing and not an endorsement by Tailscale. Third-party marks are used only as identifiers.

The records are synthetic, public-safe notes for exercising Contextarr validation, review, render, compose, and export flows. The pack contains no credentials, no private data, no install hooks, and no executable commands.

## Why this pack exists

This pack shows how a private network can document trust posture, stale-device review, sharing boundaries, and route ownership without exporting tailnet data.

## What an AI can safely know

An AI can know synthetic device classes, route categories, ownership expectations, review cadence, and public-safe support boundaries.

## What must never be exported

Never export auth keys, device node keys, real user names, live tailnet names, private routes, DNS names, invite links, ACL files, device identifiers, or provider-console details.

## Best export target

Use the Claude or Codex export for policy review. Use Markdown when a human wants a compact public-safe summary of route and device posture.

## Demo question to ask

Which stale-device or subnet-route fact needs review?

## Proof path

Review `records/device-inventory.md`, `records/subnet-routes.md`, `raw/device-inventory.md`, and `raw/subnet-routes.md` to confirm stale-device and route-review facts are specific but synthetic.
