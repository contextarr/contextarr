# Maintenance Cadence

## Summary

The fictional operator reviews workstation context on a predictable cadence so assistants can distinguish current guidance from stale setup notes.

## Cadence

| Interval | Review Focus |
|---|---|
| Weekly | Confirm active project and model asset notes still match demo intent |
| Monthly | Review storage categories, local service assumptions, and export samples |
| Before demos | Confirm all records remain public-safe and approved |
| After incidents | Capture the symptom pattern without adding private logs |

## Notes

The cadence is a public-safe maintenance pattern and does not imply any real monitoring schedule.
