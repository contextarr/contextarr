# Storage Layout

## Summary

The demo workstation keeps operating system files, project repos, generated artifacts, and model assets in separate top-level locations.

## Layout

| Area | Purpose |
|---|---|
| System volume | Operating system and base tools |
| Projects volume | Source repos and workspaces |
| Models volume | Local model files and test assets |
| Archive volume | Snapshots and completed experiments |

## Notes

This is a planning pattern only. It does not represent Rob's real workstation or any private storage map.
