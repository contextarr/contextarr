# AI Workstation Pack

Public-safe demo context for a fictional local AI developer workstation.

This pack is fake and exists to show how Contextarr can organize hardware, local model tooling, storage, networking, and troubleshooting notes.

## Why this pack exists

AI Workstation Pack demonstrates how a maintainer can turn scattered local AI workstation notes into reviewed, public-safe context for assistant troubleshooting. It keeps hardware, storage, model-serving, dashboard, and maintenance facts specific enough to be useful while staying synthetic.

## What an AI can safely know

An AI can safely know the fictional workstation's component roles, capacity signals, escalation order, review cadence, and approved troubleshooting boundaries. It can compare symptoms against the pack's role-based services and suggest which reviewed record to inspect first.

## What must never be exported

Never export real hostnames, account names, local paths, private network details, credentials, tokens, license keys, private model names, live logs, shell commands, or executable repair instructions.

## Best export target

Use the Codex or Claude target when preparing an agent troubleshooting brief. Use Markdown when a human operator needs a compact review artifact.

## Demo question to ask

Which local AI service should I inspect first if inference feels slow?

## Proof path

Start with the local AI stack record, then compare the troubleshooting workflow, capacity planning, and maintenance cadence records. The expected proof is a short, source-backed answer that names the likely layer without exposing private machine details or issuing commands.
