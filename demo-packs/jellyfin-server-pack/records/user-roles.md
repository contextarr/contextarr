# User Roles

## Summary

The demo server uses generic role groups to keep media administration separate from normal viewing.

## Roles

| Role | Demo Access |
|---|---|
| Administrator | Library and system settings |
| Household Viewer | Normal playback |
| Guest Viewer | Limited sample library |
| Maintenance Reviewer | Read-only health checks |

## Notes

All users are fictional. No real names, accounts, or emails are included.
