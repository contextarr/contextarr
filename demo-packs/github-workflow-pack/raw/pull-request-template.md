# Pull Request Template Source Note

PR template summary for a fictional project.

Pull requests should state the problem, the scoped fix, tests run, and any explicit non-actions. For launch-facing work, the template asks authors to call out whether they changed public claims, screenshots, or demo-pack inventory.

## Synthetic PR Review Notes

The template has four fictional review lanes: intent, verification, risk, and non-actions. Intent explains the scoped problem. Verification names the evidence category rather than executable steps. Risk captures export, public-copy, and security-review concerns. Non-actions prevent follow-up agents from assuming omitted work was forgotten.

The source is public-safe and does not contain real contributor emails, repository links, issue identifiers, tokens, workflow secrets, copied platform documentation, or automation instructions.
