# Manual Prompt Baseline

Use this public-safe demo context:

- Ticket intake captures product area, customer-visible symptom, urgency, and safe reproduction notes.
- Customer replies should be concise, evidence-backed, and free of internal-only context.
- The response should confirm uncertainty when more information is needed.
- The response should give one clear next step.
- Report delay issues may be handled by explaining the expected processing window.
