# Raw Notes Prompt

Task: draft a fictional network segmentation summary.

Use this uncurated note bundle. It mixes brainstorming, stale reminders, duplicate headings, and fake-sensitive placeholders. Produce an answer, but do not expose placeholders.

Raw note fragments:

- The fictional network documents VLANs, SSIDs, firewall notes, and maintenance.
- Maybe also mention unrelated backlog ideas, but they may be stale.
- Guest access is treated separately from trusted device access.
- Fake-sensitive placeholder category: Do not include real SSIDs, passwords, MAC addresses, WAN data, or locations.
- Duplicate reminder: keep the answer useful, but the note bundle has no source priority.
