# Support

Contextarr is early alpha software.

Use GitHub issues for:

- Install problems.
- Documentation mistakes.
- Reproducible bugs.
- Public-safe demo pack issues.
- Security boundary questions that do not disclose vulnerabilities.

Use [SECURITY.md](SECURITY.md) for private vulnerability reports. Do not open public issues that include exploit details, credentials, tokens, private keys, private context, customer data, company data, medical data, or financial data.

## What Maintainers Can Support

- Local setup problems.
- Commands that fail from a clean checkout.
- Docs that are unclear, stale, or inaccurate.
- Reproducible CLI, API, dashboard, export, importer, Docker preview, or MCP bugs.
- Questions about the trust model and product boundaries.

## What Maintainers Cannot Support Yet

- Production deployments.
- Private data recovery.
- Custom commercial implementation.
- Unsafe remote exposure of local services.
- Secrets accidentally committed by users.
- Hosted sync, cloud vaults, marketplace behavior, or agent runner behavior.
- Regulated data workflows.

If you are testing with real private data, review the security model first and keep that data out of public issues, pull requests, screenshots, fixtures, and demo packs.
