# Homelab Troubleshooting Kit

Public-safe kit for organizing local homelab troubleshooting context into assistant-ready notes.

## Purpose

Use this kit to structure troubleshooting observations, likely causes, and safe next checks.

## Intended Use

Prepare a calm troubleshooting brief without requesting credentials or remote access.

## Included Context Packs

- jellyfin-media-server-pack
- ai-workstation-pack

## Included Skills

- homelab-troubleshooting-skill
- support-ticket-writing-skill

## Safety Notes

- Data is fake and public-safe.
- The kit is data-only and non-executable.
- Generated briefs are derived artifacts, not source of truth.
- Pack and Skill files stay unchanged during preview or export.
