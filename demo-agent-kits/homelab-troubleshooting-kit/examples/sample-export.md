# Homelab Troubleshooting Kit Sample Export

## Kit Summary

Use this kit to structure troubleshooting observations, likely causes, and safe next checks.

## Task Goal

Prepare a calm troubleshooting brief without requesting credentials or remote access.

## Included Materials

Context Packs:
- jellyfin-server-pack
- ai-workstation-pack

Skills:
- homelab-troubleshooting-skill
- support-ticket-writing-skill

## Example Output Shape

1. Situation summary.
2. Relevant context.
3. Suggested response or implementation outline.
4. Review checklist.
5. Open questions.

## Guardrails

- Keep changes advisory and reviewable.
- Prefer observed symptoms over guesses.
- Keep private machine details out of the public-safe brief.
