# Claude Code Implementation Kit

Public-safe kit for preparing coding-agent implementation briefs from demo project context.

## Purpose

Use this kit to outline a coding-agent task with tests, boundaries, and review notes.

## Intended Use

Prepare an implementation brief that is useful for Codex or Claude-style coding agents.

## Included Context Packs

- claude-code-project-pack

## Included Skills

- implementation-planning-skill
- bug-report-structuring-skill
- security-review-skill

## Safety Notes

- Data is fake and public-safe.
- The kit is data-only and non-executable.
- Generated briefs are derived artifacts, not source of truth.
- Pack and Skill files stay unchanged during preview or export.
