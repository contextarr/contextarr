# Security Review Kit

Public-safe kit for reviewing fictional project and operations notes for safety issues.

## Purpose

Use this kit to prepare a deterministic security review brief with clear severity language.

## Intended Use

Identify safety-sensitive areas from demo context while preserving non-execution boundaries.

## Included Context Packs

- claude-code-project-pack
- jellyfin-server-pack

## Included Skills

- security-review-skill
- homelab-troubleshooting-skill

## Safety Notes

- Data is fake and public-safe.
- The kit is data-only and non-executable.
- Generated briefs are derived artifacts, not source of truth.
- Pack and Skill files stay unchanged during preview or export.
