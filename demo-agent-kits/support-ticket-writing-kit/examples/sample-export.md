# Support Ticket Writing Kit Sample Export

## Kit Summary

Use this kit to turn known issue notes into concise support-ticket drafts.

## Task Goal

Prepare customer-safe ticket language with reproducible facts and escalation cues.

## Included Materials

Context Packs:
- internal-support-kb-pack
- fake-product-line-pack

Skills:
- support-ticket-writing-skill
- bug-report-structuring-skill

## Example Output Shape

1. Situation summary.
2. Relevant context.
3. Suggested response or implementation outline.
4. Review checklist.
5. Open questions.

## Guardrails

- Use fake customer placeholders only.
- Separate symptoms, impact, and expected behavior.
- Avoid promising fixes or dates.
