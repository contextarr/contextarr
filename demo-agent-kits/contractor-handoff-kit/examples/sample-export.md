# Contractor Handoff Kit Sample Export

## Kit Summary

Use this kit to produce a bounded handoff with scope, constraints, and review checkpoints.

## Task Goal

Prepare a contractor-ready brief that avoids private data and keeps ownership boundaries clear.

## Included Materials

Context Packs:
- claude-code-project-pack
- ai-workstation-pack

Skills:
- contractor-briefing-skill
- implementation-planning-skill

## Example Output Shape

1. Situation summary.
2. Relevant context.
3. Suggested response or implementation outline.
4. Review checklist.
5. Open questions.

## Guardrails

- Keep the work order narrow.
- List deliverables and review criteria.
- Keep generated drafts outside source-of-truth files.
