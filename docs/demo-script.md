# Contextarr Demo Script

## Title

Stop re-explaining your systems to AI.

## Flow

1. Open a fresh AI assistant session.
2. Ask a specific question about a fake AI workstation or starter pack domain.
3. Show that the assistant lacks enough context.
4. Open Contextarr locally.
5. Show the Pack Library with the 12 curated starter Context Packs clearly marked as local examples.
6. Open AI Workstation Pack or Claude Code Project Pack.
7. Show records, sources, Pack Health, and review queue.
8. Preview a Claude or Codex export.
9. Use the export or read-only MCP to answer the same question.
10. Show the improved answer.
11. Delete or ignore the SQLite database and run a rescan to show the index is rebuildable from local files.
12. Open the raw Markdown files to prove local ownership.
13. Open the Docker preview at `http://127.0.0.1:3210`.
14. End with the quickstart docs, known limitations, and the GitHub repo.

## Optional Advanced Preview Mention

If asked, show that Skills and Agent Kits exist as advanced-preview data objects. Keep the wording clear: Contextarr prepares Agent Kits, but it does not run them.

## Demo Data Rules

- Use fake data only.
- Use public-safe examples only.
- Do not include credentials.
- Do not include real private system details.
- Do not call external AI APIs during the repository demo unless explicitly approved later.
- Do not show marketplace, cloud sync, telemetry, executable pack behavior, Skill execution, or Agent Kit runtime behavior.
