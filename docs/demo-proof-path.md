# Demo Proof Path

## Purpose

The first demo must prove Contextarr's reason to exist in minutes: one source-backed Context Pack can become many safer, better AI outputs without hidden cloud, execution, or private data.

## Required Demo

Title:

```text
Stop re-explaining your systems to AI.
```

Flow:

1. Open a fresh AI session with no Contextarr output.
2. Ask a specific question about a demo system.
3. Show weak or generic answer.
4. Open Contextarr.
5. Show a demo Context Pack.
6. Show records, sources, Pack Health, and Review Queue.
7. Export a Claude or ChatGPT brief.
8. Export a Codex implementation brief.
9. Show AGENTS.md or CLAUDE.md output.
10. Query approved context through read-only MCP, if MCP phase exists.
11. Ask the same question again.
12. Show improved answer.
13. Open raw Markdown files.
14. Delete SQLite and rebuild, if Phase 3 exists.
15. Show no hidden execution, no hidden cloud, no telemetry.

## In-App Proof Path

- Demo mode should work without private data.
- Demo packs should be enough to understand value.
- The user should understand the product within five minutes.
- The demo must prove one source, many outputs.
- The demo should show why a record was included in an export.
- The demo should show what was excluded, redacted, stale, unreviewed, or blocked.

## Demo Pack Requirements

- Use only fake public-safe content.
- Include at least one technical system pack and one operational or support-process pack.
- Include source-backed records, review status, privacy metadata, and export profiles.
- Include at least one warning-ready example in fixtures or a controlled demo state without shipping unsafe public data as trusted content.
- Avoid real user, customer, financial, health, credential, or private company data.

## Proof Claims

The demo must support these claims with visible evidence:

- Contextarr is not generic memory.
- Contextarr does not require private data to show value.
- Contextarr keeps files as source of truth.
- SQLite is derived and rebuildable.
- Exports are target-specific.
- MCP is read-only.
- Review and redaction state affect output.
- The product can improve an AI answer without becoming a chatbot.

## Future Optional UI

- "Ask without context" sample prompt.
- "Export best brief".
- "Show why included".
- "Show source".
- "Show what was redacted".
- "Show what blocks export".

## Acceptance Criteria

- A skeptical power user can complete the demo path without reading the whole PRD.
- The second AI answer is visibly more specific than the first.
- The user can inspect the exact source files behind the improved answer.
- The demo does not imply hosted sync, telemetry, remote marketplace, agent execution, or private connectors.
