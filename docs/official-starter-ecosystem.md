# Official Starter Ecosystem

Status note: Check [implementation-status.md](implementation-status.md) before treating starter gallery, export targets, templates, registry behavior, or marketplace behavior as shipped.

## Purpose

The Official Starter Ecosystem is a Good-to-Great planning addition for helping users understand Contextarr quickly through safe, curated examples.

This document is docs-only. It does not add starter packs, templates, export profiles, a starter gallery UI, registry behavior, marketplace behavior, cloud services, or telemetry in this pass.

## Product Problem

Contextarr will be easier to understand when users can see good examples immediately. A starter ecosystem should teach conventions without requiring private data, third-party uploads, or marketplace trust.

The starter ecosystem is not a marketplace. It is official, curated, fake or public-safe, and designed to teach the pack format, review model, redaction posture, export profiles, and agent-safe workflows.

## Local Starter Gallery

A future local Starter Library or Starter Gallery may display official content only.

It may show:

- Official packs.
- Templates.
- Export profiles.
- Benchmark tasks.
- Trust level.
- Validation status.
- Source count.
- Record count.
- Create-from-template actions.
- Demo opening actions.

It must not imply a public marketplace, community upload system, remote install lane, payment flow, or unreviewed third-party artifact trust.

## Official Content Policy

Official starter content must follow these rules:

- Official-only until registry trust work is explicitly scoped.
- Fake or public-safe data only.
- Data-only artifacts.
- No executable pack content.
- No executable Skills.
- No Agent Kit runtime.
- No hidden network calls.
- No telemetry.
- No third-party docs dumps.
- No private or sensitive account data.
- Clear source maps and licenses.
- Human review before approval.

## Non-Goals

Do not build in this pass:

- New starter packs.
- Template folders.
- Export profile templates.
- Starter gallery UI.
- Public registry.
- Marketplace.
- Community uploads.
- Remote install.
- Payments.
- Cloud services.
- Telemetry.
- Skills.
- Agent Kits.

## Acceptance Criteria

This layer succeeds when users can learn Contextarr from official, safe, source-backed examples and templates without introducing marketplace risk or weakening the no-execution boundary.
