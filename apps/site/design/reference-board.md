# Contextarr Site Reference Board

This board is for the local static site redesign. It is not a request to copy another site. The goal is to borrow durable design moves from strong developer-tool sites and apply them to Contextarr's real product object: Context Packs.

## Current Problem

The current homepage is accurate, but it looks assembled from generic dark SaaS blocks. It overuses glowing cards, grids, chips, and simulated product panels. The page needs one confident visual argument:

> Contextarr turns local source material into validated, reviewable, exportable Context Packs.

## References Checked

- Supabase: developer-platform clarity, product object first, strong command-line and dashboard proof.
- PostHog: memorable operating-system metaphor, blunt product personality, dense but legible modules.
- Langfuse: real workflow depth, technical audience confidence, screenshots that show product complexity.
- Coolify: self-hosted positioning without enterprise gloss.
- Ollama and Vite: one simple command or artifact as the center of gravity.
- Baymard homepage/navigation research: expose the user's key paths clearly instead of burying them behind clever navigation.
- Figma UI principles: hierarchy, spacing, typography, and consistency must carry the design before decoration.
- Figma typography system guidance: type scale and naming need to be deliberate, not incidental.
- Landingfolio/Mobbin-style galleries: useful only as pattern references; avoid their generic template look.

## Borrow

- Product proof early, not fake imagery.
- A single repeated visual grammar: records, manifests, source maps, export profiles, review state.
- Dense operator-console details where they explain real behavior.
- Clear hierarchy: headline, product object, proof, current status, security boundaries.
- Strong typography with restraint. Use self-hosted technical fonts instead of external calls.
- Fewer cards. More ruled sections, tables, frames, and real screenshot plates.

## Avoid

- Placeholder screenshot in the hero.
- Fake dashboards, fake logs, fake customer logos, fake testimonials.
- Gradient-heavy AI launch-page styling.
- Card stacks that all have the same weight.
- Claims that Contextarr is production-ready, cloud-hosted, a marketplace, an agent runner, or generic AI memory.
- Making Skills or Agent Kits the main message. They stay in a future-direction section.

## Chosen Visual Direction

Use a "technical field manual + real dashboard proof" direction:

- Near-black product surface with a restrained paper/manual section rhythm.
- Large editorial headline, not a tiny SaaS headline.
- Real Contextarr dashboard screenshot as the first concrete proof.
- Context Pack anatomy shown as a manifest/record/source/export object, not a decorative diagram.
- Current implementation shown as a sober build ledger.
- Security boundaries presented like a threat-model checklist, not marketing trust copy.
