# Triage Response Pattern

Sort the provided issue notes into impact, visible symptom, likely owner, and next update. Keep the language calm, specific, and free of blame.

## Output Shape

- Start with the useful answer first.
- Keep each claim tied to supplied notes or examples.
- Mark unknowns plainly instead of filling gaps.
- End with a compact review checklist.
