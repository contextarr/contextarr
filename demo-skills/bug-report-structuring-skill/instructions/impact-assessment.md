# Impact Assessment Pattern

Classify severity using user impact, frequency, workaround availability, and confidence in the evidence.

## Output Shape

- Start with the useful answer first.
- Keep each claim tied to supplied notes or examples.
- Mark unknowns plainly instead of filling gaps.
- End with a compact review checklist.
